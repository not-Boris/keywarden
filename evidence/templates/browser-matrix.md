# Browser Test Matrix

## How To Complete

1. Copy this template into a run folder (or let `collect_evidence.sh` do it).
2. Fill metadata first: date, URL, commit.
3. For each browser cell, use one of: `PASS`, `FAIL`, `PARTIAL`, `N/A`.
4. Add a short symptom in `Notes` for every non-pass result.
5. Add exact artifact paths in `Evidence Path` (screenshots/HAR/console output).
